## Upload to GitHub
1. Open your `Personal-Portfolio-Website` repository.
2. Replace `index.html`, `style.css`, and `script.js`.
3. Upload your real profile photo as `profile.jpg` in the repository root.
4. Commit changes.
5. Open GitHub Pages again.

Important: The HTML expects the photo filename to be exactly `profile.jpg`.
